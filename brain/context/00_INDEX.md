# Brain Index

Mapa de leitura do Dev Brain do FlowCore.

## Ordem Obrigatoria Para IA

1. `brain/canonico/CURRENT_STATE.md` - estado real atual do projeto.
2. `brain/context/01_SYSTEM_OVERVIEW.md` - resumo tecnico em uma pagina.
3. `brain/canonico/DECISIONS.md` - decisoes ja tomadas.
4. `brain/canonico/NEXT_ACTIONS.md` - proximas sessoes recomendadas.
5. `brain/architecture/` e `brain/product/` - detalhes conforme a tarefa.

## Arquivos Principais

- `brain/CLAUDE.md` - regras de trabalho para agentes IA.
- `brain/PENDING_UPDATES.md` - fila de lacunas a confirmar.
- `brain/canonico/CURRENT_STATE.md` - save game do projeto.
- `brain/canonico/NEXT_ACTIONS.md` - proximas acoes.
- `brain/canonico/DECISIONS.md` - log resumido de decisoes.
- `brain/canonico/KNOWN_ISSUES.md` - bugs, riscos e limitacoes conhecidas.
- `brain/context/01_SYSTEM_OVERVIEW.md` - visao geral curta do sistema.

## Pastas

- `brain/architecture/` - mapas tecnicos, stack, modulos, dados, eventos e infraestrutura.
- `brain/product/` - funcionalidades, jornadas, regras de negocio e UX.
- `brain/decisions/` - ADRs individuais e detalhados.
- `brain/runbooks/` - procedimentos operacionais e checklists.
- `brain/handoffs/` - continuidade entre sessoes.
- `brain/draft/` - rascunhos e ideias ainda nao canonicas.
- `brain/changelog/` - historico enxuto de mudancas relevantes.
