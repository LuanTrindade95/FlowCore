# Decisions

Use esta pasta para ADRs individuais e detalhados.

O arquivo `brain/canonico/DECISIONS.md` guarda o log resumido. Esta pasta guarda o contexto completo de decisoes que impactam arquitetura, dominio, dados, seguranca, UX estrutural ou operacao.

Cada ADR deve conter:

- contexto
- opcoes consideradas
- decisao
- consequencias
- data
- status
