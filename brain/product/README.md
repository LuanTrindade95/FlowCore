# Product

Use esta pasta para documentar o que o FlowCore faz para usuarios e empresas.

Inclua aqui:

- jornadas de usuario
- fluxos de aprovacao
- regras de negocio
- permissoes
- personas
- UX esperada
- criterios de aceite
- escopo funcional

Como o projeto deve evitar aparencia de CRUD generico, esta pasta precisa preservar o raciocinio de produto por tras das telas e funcionalidades.
