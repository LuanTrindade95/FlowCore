# Handoffs

Use esta pasta para registrar continuidade entre sessoes.

Crie um handoff quando uma sessao terminar no meio de uma investigacao, modelagem, implementacao ou decisao.

Um bom handoff registra:

- objetivo da sessao
- o que foi feito
- estado atual
- arquivos relevantes
- decisoes tomadas
- proximos passos
- riscos ou bloqueios
